# Contributing

1. One skill per folder under `skills/`, following [STYLE.md](STYLE.md).
2. Run `npm test` (zero dependencies, Node 18+) before opening a PR.
3. Add the skill to the table in `README.md`.
4. Prefer fixing a wrong rule over adding a new one. A skill that is 20%
   shorter and still correct is a good PR.
5. Everything you submit must be your own writing, licensed MIT. Do not paste
   official documentation, blog posts or code from other licenses.
